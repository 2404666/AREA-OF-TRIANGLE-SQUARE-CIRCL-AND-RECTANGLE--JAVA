# 📐 Area Calculator

A simple Java program that calculates the area of four basic geometric shapes: **Triangle**, **Rectangle**, **Square**, and **Circle**. The program accepts user input and computes the area using the appropriate mathematical formula.

##  Features

- Calculate the area of a Triangle
- Calculate the area of a Rectangle
- Calculate the area of a Square
- Calculate the area of a Circle
- Uses the `Scanner` class for user input
- Demonstrates the use of variables and arithmetic operations in Java

##  Formulas Used

### Triangle
Area = ½ × Base × Height

### Rectangle
Area = Length × Width

### Square
Area = Side × Side

### Circle
Area = π × Radius × Radius

##  Technologies Used

- Java
- Scanner Class
- NetBeans IDE
- VS-code

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Area-Calculator.git
   ```

2. Open the project in NetBeans or any Java IDE.

3. Compile and run the program.

4. Enter the required dimensions for the shape.

5. The program displays the calculated area.
